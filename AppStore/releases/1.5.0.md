# MyStat 1.5.0

Native macOS menus and a smaller Keep Awake indicator.

- The dropdown now uses AppKit's native menu, with real cascading submenus for CPU Processes, Memory Processes, Details, iPhone, and Settings.
- macOS handles submenu placement, selection highlights, checkmarks, keyboard navigation, and dismissal. Charts and Keep Awake controls remain available in the overview.
- Process lists use native rows with app icons and live usage values. Readings and countdowns continue updating while a menu is open.
- Keep Awake now adds just 23 points to the menu bar: a small coffee icon and a progress bar that shrinks as time runs out. Hover for the exact remaining time; untimed sessions show ∞.
- Duration and display options remain under the Keep Awake heading. Changing duration restarts the timer; changing the display option preserves its deadline.

Developer ID signed and Apple-notarized. Universal Apple silicon / Intel app, macOS 12+.

Install through **Settings → Check for Updates… → Install Update → Install and Relaunch**. Saved preferences are preserved. Relaunching ends an active Keep Awake session; enable it again after the update if needed.

This release updates the Mac companion only.
