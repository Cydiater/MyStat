# MyStat 1.1.0

**GitHub-only macOS release:** this universal Apple silicon / Intel build is ad-hoc signed and is not Apple-notarized. macOS may block its first launch. This version is a manual download and is not advertised in the automatic update feed.

- Hover over the Mac's CPU or memory chart for its top-five process list; click to keep it open. Process data also supports the forthcoming iPhone update.
- Check for updates from the MyStat menu, read release notes, and install without manually replacing the app.
- Optionally enable automatic update checks. Installation remains your choice.
- Find the installed version and build in About MyStat.

Requires macOS 12 or later. Process lists show readable processes; CPU uses 100% per core and memory uses resident bytes. Updating the iPhone app is required to view process rankings there.

If you are upgrading from MyStat 1.0.0 or earlier, download this version once and replace the old app in Applications. Future signed releases published to the update feed can be installed through Check for Updates.

This release updates the free Mac companion only; the iPhone App Store release is separate.
