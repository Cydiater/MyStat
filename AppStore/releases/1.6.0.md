# MyStat 1.6.0

Network activity alongside CPU and memory.

- A compact NET graph in the menu bar shows download above the center line and upload below it.
- The overview includes download/upload rates and a network chart with the same 3m, 15m, and 1h ranges as CPU and memory. Missing samples leave gaps.
- The native Network Apps submenu shows the top five active apps and system processes, with icons and separate download/upload rates. Helpers belonging to the same app are combined.
- Network collection uses macOS's built-in tools without administrator privileges. Overall rates cover physical Wi-Fi and Ethernet; VPNs and proxies can make app rates differ from those totals. Empty, unavailable, and stale readings are labeled.
- Submenu headings no longer show hover tooltips that can cover an open panel, including the Upload heading in Details.
- The companion can share network app rankings with the matching iPhone source. Older phone clients remain compatible.

Developer ID signed and Apple-notarized. Universal Apple silicon / Intel app, macOS 12+.

Install through **Settings → Check for Updates… → Install Update → Install and Relaunch**. Saved preferences are preserved. Relaunching ends an active Keep Awake session; enable it again after the update if needed.

This release updates the Mac companion. The matching iPhone changes are synced in source and have not been submitted to the App Store.
