# MyStat 1.2.1

Clicking the menu-bar graphs again now reliably dismisses the dashboard.

- Fixed a timing race that could close the pop-up on mouse-down and immediately reopen it on mouse-up.
- Closing the dashboard also dismisses an attached process panel. Clicking inside a process panel still keeps the dashboard open.
- Chart hover and keyboard tracking now starts only when the dashboard opens.

**GitHub-only macOS release:** universal Apple silicon / Intel, macOS 12+. This build is ad-hoc signed and not Apple-notarized; macOS may block its first launch. Check for Updates offers a “Learn More…” link to this GitHub download. Installation is manual; Sparkle does not automatically download or install this build.

Quit MyStat before replacing the app in Applications. This updates the Mac companion only; the iOS submission is unchanged.

Validation: all 30 core tests, dropdown layout and side-panel placement checks, repeated menu-button toggles, and dismissal with a process panel attached. The universal release build includes a SHA-256 checksum. Automated desktop UI inspection was unavailable; interaction checks exercised the AppKit popover directly.
