# MyStat 1.5.1

A simpler Keep Awake menu and restored process icons.

- Keep Awake is now a single row in the overview, showing Off or the remaining time. Its native submenu contains the on/off control, duration presets, and Keep Display On, with standard checkmarks.
- CPU and memory process lists explicitly show their app icons on macOS 27, where automatic menu-image visibility could hide them.
- Changing the duration restarts an active session; changing Keep Display On preserves its deadline. Saved preferences and the compact menu-bar progress indicator are preserved.
- Session status continues updating while menus are open. Failed changes leave the existing session intact and show an error.

Developer ID signed and Apple-notarized. Universal Apple silicon / Intel app, macOS 12+.

Install through **Settings → Check for Updates… → Install Update → Install and Relaunch**. Saved preferences are preserved. Relaunching ends an active Keep Awake session; enable it again after the update if needed.

This release updates the Mac companion only.
