# MyStat 1.3.0

A more focused Mac dropdown with native translucent materials and Liquid Glass on macOS 26 and later.

- **Overview** keeps CPU, memory, and a compact Keep Awake switch close at hand. Click the Keep Awake heading to reveal duration and display options.
- **Details**, **iPhone**, and **Settings** put additional readings, connected devices, and app controls on separate pages. Back or Escape returns to Overview; reopening the dropdown always starts there.
- Floating process panels and Back buttons use native Liquid Glass on macOS 26+. Older versions of macOS use native fallback materials and controls.
- System colors, lighter chart styling, and standard segmented controls adapt to light and dark appearance. Reduce Transparency and Increase Contrast are respected.
- Corrected the build's SDK metadata so AppKit uses the current native control design while retaining macOS 12 compatibility.
- Preserved reliable menu-bar dismissal, process-panel interactions, keyboard shortcuts, and Keep Awake preferences.

**GitHub-only macOS release:** universal Apple silicon / Intel, macOS 12+. This build is ad-hoc signed and not Apple-notarized; macOS may block its first launch. Check for Updates offers a “Learn More…” link to this GitHub download. Installation is manual; Sparkle does not automatically download or install this build.

Quit MyStat before replacing the app in Applications. Quitting ends an active Keep Awake session; enable it again after relaunching if needed. This updates the Mac companion only; the iOS submission is unchanged.

Validation: all 30 core tests, dropdown hierarchy and layout checks, keyboard navigation, repeated menu-button dismissal, side-panel placement, Keep Awake session lifecycle and native sleep assertions, and live light/dark appearance checks. The universal release archive includes a SHA-256 checksum.
