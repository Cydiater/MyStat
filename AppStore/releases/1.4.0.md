# MyStat 1.4.0

See how long Keep Awake has left without opening the dropdown.

- A compact coffee-cup badge beside the menu-bar graphs shows the remaining time, updated every second.
- Untimed sessions show ∞. The badge disappears when the session ends or Keep Awake is switched off.
- Fixed-width digits keep neighboring menu-bar items steady, including when the countdown passes below one hour.
- The badge follows the system menu-bar tint in light and dark appearance, with a descriptive tooltip and VoiceOver value.
- Changing the duration restarts the countdown; changing the display option preserves the deadline.

Developer ID signed and Apple-notarized. Universal Apple silicon / Intel app, macOS 12+.

Install through **Settings → Check for Updates… → Install Update → Install and Relaunch**. Saved preferences are preserved. Relaunching ends an active Keep Awake session; enable it again after the update if needed.

This release updates the Mac companion only.
