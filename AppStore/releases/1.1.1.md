# MyStat 1.1.1

Fixes the macOS dropdown layout regression in 1.1.0: the large blank area, range selector at the bottom, and controls overlapping system readings.

- Charts, readings, and actions now retain their positions when the dropdown opens or connected devices change.
- CPU and memory process previews remain attached to their charts, with click-to-pin and C/M keyboard controls.

**GitHub-only macOS release:** universal Apple silicon / Intel, macOS 12+. This build is ad-hoc signed and not Apple-notarized; macOS may block its first launch. It is a manual download and is not advertised in the automatic update feed.

Quit MyStat before replacing the app in Applications. This updates the Mac companion only.
