# App Store screenshots

Captured from MyStat running on an iPhone 17 Pro Max simulator (iOS 26.5), using the customer-visible DEMO mode. These are actual app screens with fictional measurements and a generic Mac name. No personal usage or device names are included.

- `01-desk-display.jpg`: portrait desk display, 1320 × 2868.
- `02-dashboard.jpg`: portrait dashboard, 1320 × 2868.
- `04-landscape.jpg`: landscape desk display, 2868 × 1320.

Upload to the 6.9-inch iPhone screenshot group. JPEG exports are opaque; the landscape capture was rotated to match its display orientation. No UI or readings were composited over the screenshots.
